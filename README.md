# Neil's Tennis Tactics (NTT)

A modern, high-performance web platform and digital ecosystem engineered for Neil Raychaudhuri's private tennis consultancy. The site blends Division 1 collegiate mastery and luxury club director pedigree with cutting-edge biomechanical telemetry, tactical video analysis, regional court booking across the San Gabriel Valley, and upcoming branded performance gear.

---

## ⚡ Key Highlights
* **Visual Identity & HUD Telemetry:** Optic volt accents, sleek hardcourt night palette, and diagnostic data overlays.
* **Tour Pedigree Integration:** Highlights Coach Neil’s credentials as an NCAA D1 MAC Champion, former Cliff Drysdale Tennis Director, and preventive performance specialist.
* **SGV Court Circuit:** Regional court routing across Pasadena, Arcadia, San Marino, and Alhambra.
* **Interactive Architecture:** Scroll-spy navigation, tactical video breakdown vaults, tiered training rates, and an apparel drop waitlist.

---

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Language:** TypeScript
* **Icons:** Lucide React
